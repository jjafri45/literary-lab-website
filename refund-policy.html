Refund Policy

This page outlines how Literary Lab handles deposits, revision scope, cancellations, and refund requests for digital publishing and design services.

Project Scope First

Work begins only after the project scope, deliverables, pricing, and revision expectations are confirmed in writing. This reduces misunderstandings and protects both sides before production starts.

Deposits and Payments

If a deposit or partial payment is required, that amount is generally reserved against scheduling, planning, and production time. Payment structure may vary by project type, complexity, and turnaround needs.

Digital Services Are Limited-Refund Work

Because book design, formatting, proofreading, and publishing support are digital services based on time and labor, completed work, approved concepts, delivered files, and revision time already used are generally non-refundable.

Cancellation Before Work Starts

If a project is cancelled before any meaningful work begins, any refund is handled case by case based on whether planning, intake review, or scheduling commitments have already been performed.

Cancellation After Work Starts

If work has already started, any refund request is reviewed against the production stage reached, concepts delivered, revision rounds used, and the value of work already completed.

Technical Revisions

If a publishing platform flags a technical file issue related to Literary Lab's file setup within the agreed scope, we aim to correct that issue. This technical support is not the same as an open-ended refund right.

Questions About Billing

If you need to discuss project billing or a refund-related concern, contact studio@literarylabstudio.com with the project name, delivery stage, and issue summary.
